# Launch checklist

Tick every item before announcing the site. Details for each are in docs/DEPLOY.md and docs/HANDOFF.md.

## Accounts and keys

- [ ] **Firebase**: project on the **Blaze** plan with a **budget alert**; Phone sign-in enabled; **authorized domains** include the production domain (and the Vercel preview domain for testing); production web config (`NEXT_PUBLIC_FIREBASE_*`) and service account (`FIREBASE_ADMIN_*`) set in Vercel Production; test phone numbers configured for staff testing; `AUTH_OTP_STUB` is **not** set in production.
- [ ] **Database**: production Postgres created, `prisma migrate deploy` run, automated backups on, restore drill done once.
- [ ] **Storage**: Supabase public bucket `uploads` created; keys set.
- [ ] **Cashfree** (only if paid entry is enabled): production PG keys, Payouts keys, `CASHFREE_ENV=production`; webhook URLs set in both dashboards (`/api/webhooks/cashfree`, `/api/webhooks/cashfree-payouts`); a ₹1 real payment + refund and a ₹1 payout tested end to end.
- [ ] **VAPID keys** generated and set; push tested on an installed PWA in Chrome on Android.
- [ ] **Sentry** DSN (+ auth token for source maps) set; test event received.
- [ ] **Uptime checks** on `/` and `/api/health`.
- [ ] `SESSION_SECRET`, `CRON_SECRET` set (random, not reused from any other environment).
- [ ] Vercel **Pro** plan (or an external scheduler) so the 5- and 10-minute crons run.

## Content and setup

- [ ] **Admin phone seeded** (`ADMIN_PHONE` + `npm run db:seed`), admin can log in; moderators appointed from Admin → Users.
- [ ] **First season dates set** for all three games (Admin → Seasons; the seed starts Season 1 on the seed day).
- [ ] **Rules** per game and general scoring / no-show / dispute rules written (Admin → Content).
- [ ] **FAQ** written.
- [ ] **Terms, privacy policy and refund policy** replaced with lawyer-reviewed text (the shipped text is a placeholder).
- [ ] **Social links** set (WhatsApp Channel, Discord, Instagram, Facebook, YouTube).
- [ ] Sponsors and a first carousel card (optional).
- [ ] Points table values confirmed (currently the spec's defaults in `PointsConfig`).
- [ ] Home page stats (Admin → Content → Home page): the seeded 50K+ / 1K+ / ₹10L+ are the design's demo values. Replace them with true numbers or switch on "Use live stats" (DECISIONS H1). Set the "Watch Trailer" link if there is one.
- [ ] Product name/brand confirmed or replaced (`SITE_NAME` in `lib/site.ts`, currently the placeholder "Esports"; the icon monogram follows it automatically).
- [ ] Design artwork delivered to `docs/design/assets/` (list in docs/HANDOFF.md §4), `lib/art-manifest.ts` regenerated by a build and committed.

## Decisions to record

- [ ] **`PAYMENTS_ENABLED` decision recorded**: free entry only at launch, or paid entry (requires the state-by-state legal review in docs/SPEC.md; some states ban paid entry — consider geo-restricting).
- [ ] Policy for players **under 18** in paid matches and prizes (payouts to minors are blocked in the app until a guardian flow exists).
- [ ] Squad-only or solo/duo lobbies too; who hosts Valorant custom lobbies.

## Final checks

- [ ] CI green on `main`; Playwright passes against the Preview deployment.
- [ ] Lighthouse mobile ≥ 90 on Home, Scrims and Leaderboard on the production domain.
- [ ] `npm audit --audit-level=high` clean.
- [ ] Smoke checks in docs/DEPLOY.md §8 pass on Production.
